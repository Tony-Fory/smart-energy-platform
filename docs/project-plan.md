# 智慧能源综合管理平台（Smart Energy Platform）

## 1. 项目简介

### 1.1 项目名称

Smart Energy Platform

### 1.2 项目目标

本项目旨在构建一个智慧能源综合管理平台，通过采集家庭及工业设备运行数据，实现设备状态监控、能源消耗分析、历史趋势查询以及节能优化。

系统模拟真实能源管理系统（EMS）的核心业务流程，包括：

- 设备管理
- 数据采集
- 实时监控
- 历史数据分析
- 能耗统计
- 异常告警
- 可视化展示


## 2. 项目定位

本项目参考智慧能源管理系统（EMS）、工业互联网平台架构设计。

目标场景：

- 家庭能源管理
- 小型工业设备能源监控
- 设备运行状态分析

当前阶段采用模拟设备数据采集方式，后续支持接入真实智能硬件。

# 5. 功能规划


## 5.1 用户管理

功能：

- 用户注册
- 用户登录
- 用户权限管理

数据：

用户信息保存到 MySQL。


## 5.2 设备管理

功能：

- 添加设备
- 删除设备
- 查询设备
- 查看设备状态

当前支持设备：

- 电视机
- 电风扇

后续扩展：

- 空调
- 冰箱
- 热水器
- 智能插座


## 5.3 数据采集模块

当前实现：

模拟设备周期产生数据。

采集指标：

- 电压
- 电流
- 功率
- 累计电量
- 时间


数据采集周期：

默认10秒。


后续扩展：

支持 MQTT 协议接入真实设备。


## 5.4 能耗监控

功能：

- 实时功率展示
- 今日耗电量
- 历史趋势查询
- 能耗统计


## 5.5 数据可视化

页面展示：

首页 Dashboard：

- 在线设备数量
- 当前总功率
- 今日耗电量
- 能耗趋势折线图


图表：

使用 ECharts 实现。


## 5.6 告警管理

功能：

根据设备运行数据判断异常：

例如：

- 功率超过阈值
- 设备离线
- 电量异常


# 6. 数据存储设计


## MySQL

存储业务数据：

包括：

- 用户信息
- 设备信息
- 告警规则
- 系统配置


## TDengine

存储时序数据：

包括：

- 电压
- 电流
- 功率
- 电量
- 采集时间


设计原则：

业务数据和时序数据分离。
